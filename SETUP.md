# Setup: opening a lab in Google Colab

You need only a web browser and a Google account. No installs.

## Open a lab

1. Go to <https://colab.research.google.com>.
2. Choose **File > Open notebook > GitHub**.
3. Paste this repo's URL, press Enter, and pick the week's `lab.ipynb`.
4. Choose **File > Save a copy in Drive** so your work is saved.
5. Run the first cell. It downloads the week's data files into Colab.

## Run cells

- Click a cell and press **Shift + Enter** to run it.
- Cells marked `# TODO` are for you to complete.
- If something breaks, use **Runtime > Restart session** and run cells from the top.

## Using AI tools in this course

You may use an AI assistant only where a lab says so, and only under your school's AI policy.
When AI helps you write code or answers, say so in a comment, for example:

```python
# AI-assisted: asked an assistant how to sort a dictionary by value, then checked it myself.
```

Always test what AI gives you. Part of this course is learning where AI is wrong.
